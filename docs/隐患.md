# 隐患

### 一、 核心安全隐患

#### 1. 凭证暴露与明文存储历史

- **凭据持久化问题**：在多个版本中，该插件被安全研究人员曝出直接将用户的 Google OAuth **Access Token** 与 **Refresh Token** 以明文 JSON 格式保存在本地用户主目录下（如 `~/.antigravity_cockpit/credentials.json` 或 `%USERPROFILE%\.antigravity_cockpit\`），而未优先使用 VS Code 的系统级加密存储（`SecretStorage` / OS Keychain）。
- **横向提权风险**：任何运行在宿主机上的非提权程序或其它恶意脚本，均可直接读取该文件获取长期有效的 Refresh Token。

#### 2. OAuth Scope 权限范围过大

- 该插件在引导授权时使用了独立的 OAuth Client ID，并申请了包括 **`cloud-platform`** 在内的宽泛权限（不仅限于配额查询）。这意味着一旦 Token 泄露，攻击者理论上有权访问和操作用户绑定的 Google Cloud 项目资源。

#### 3. 供应链与网络外联不透明

- 作为第三方 VS Code 插件，其具有完整的 Node.js 运行时环境，拥有本地文件读写与任意外部网络通信权限。
- 插件内包含动态公告拉取（`announcements.json`）、外部 Web 视图通信及配套的桌面/WS 工具桥接，增加了潜在的攻击面。

### 二、 是否会触发平台风控？（高概率）

该插件的部分核心功能属于 Google 反作弊与滥用防护系统（Anti-Abuse / Risk Control）的高危监测行为：

| **触发点**                       | **机制与表现**                                               | **风控风险等级** |
| -------------------------------- | ------------------------------------------------------------ | ---------------- |
| **自动唤醒 (Auto Wake-up)**      | 利用定时任务（Crontab/循环）在闲置时发送空请求唤醒模型，以提前触发配额重置 CD 周期。这类无人工交互的周期性请求极易被 Google 流量分析判定为**自动化脚本刷量**。 | 🔴 **极高**       |
| **多账号自动切换 (Auto-switch)** | 当单账号配额耗尽时自动切号，在同一设备环境、指纹和 IP 下频繁轮换多个账号的 OAuth Token，极易触发**多号滥用/防黑产关联合规拦截**。 | 🔴 **极高**       |
| **模拟官方客户端调用内部 API**   | 插件通过逆向 Cloud Code / Antigravity 的非公开内部端点（如 `onboardUser`、`loadCodeAssist`）并伪造官方客户端的 `User-Agent` 与 Metadata 获取配额。插件更新日志中已多次出现适配 **403 Forbidden** 的补丁，说明部分接口已被官方风控拦截。 | 🟡 **高**         |
| **高频状态轮询**                 | 若用户开启了较短的配额刷新间隔（如 10–30 秒），密集请求非公开接口易直接触发速率限制（Rate Limit）或 IP 临时封锁。 | 🟡 **中~高**      |

### 三、 处置与防范建议

如果你在生产环境或主力 Google 账号上安装并授权了该插件，建议采取以下防护措施：

1. **撤销 Google 账号授权（最关键）：**

   - 打开 [Google 账号安全性 - 第三方应用和权限](https://myaccount.google.com/connections?authuser=1)；
   - 找到名为 **Antigravity** 或与该插件关联的第三方应用访问权限，点击 **“移除访问权限”**（使已发出的 Refresh Token 彻底失效）。

2. **清理本地残留明文凭据：**

   - **Windows**：检查并删除 `%USERPROFILE%\.antigravity_cockpit` 文件夹。

   - **macOS / Linux**：在终端执行：

     Bash

     ```
     rm -rf ~/.antigravity_cockpit
     ```

3. **卸载插件并重启编辑器：**

   - 在 VS Code 扩展列表中卸载 `Antigravity Cockpit`，完全退出 IDE 进程以终止后台扩展宿主。

4. **替代方案：**

   - 仅通过官方支持的客户端界面或正规控制台查看剩余额度，避免使用任何带有“自动切号”、“自动化保活唤醒”功能的第三方扩展。
